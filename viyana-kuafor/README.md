# Viyana Bayan Kuaförü – Örnek Web Sitesi

Nilüfer/Bursa'daki Viyana Bayan Kuaförü için hazırlanmış **örnek (demo)** tek sayfalık site.
Tek dosya: `index.html` (HTML + CSS + JavaScript bir arada, kurulum gerektirmez).

## Yayına almadan önce değiştirilecekler
- `WHATSAPP` sabiti ve telefon numarası (`90XXXXXXXXXX`)
- Açık adres, Instagram hesabı, Google Maps konumu
- `SERVICES` içindeki hizmet ve fiyatlar
- Unsplash stok görselleri → salonun kendi fotoğrafları
- Örnek yorumlar → gerçek Google yorumları

## Yayınlama
Netlify / GitHub Pages / Vercel'e `index.html` dosyasını yüklemek yeterli; alan adı (örn. viyanakuafor.com) bağlanabilir.
